# Embryo Snapshot

Embryo Snapshot is Embryo-Zero's fork of [kopia](https://github.com/kopia/kopia) (0f7c76c, commit 0f7c76c). It does fast encrypted backups with a web UI.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
